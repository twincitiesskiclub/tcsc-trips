## Surprises / deviations from the brief

1. **Fixture bug in the brief.** The brief's Step 1 shows two code blocks — the
   test bodies (call `db_session.add()`, `.commit()`, `.expire()`) and the fixture
   (`yield db`) — that cannot both work as literally written. Flask-SQLAlchemy's
   `db` extension object does not proxy session methods (`__getattr__` only falls
   back to names found on `sqlalchemy`/`sqlalchemy.orm`). Every other `db_session`
   fixture in the repo has the same misleading name but either (a) is only used for
   `.engine`-level access (`test_plan_reaction_migration.py`, the file the brief
   cites as "the pattern") or (b) actual test bodies call `db.session.add(...)` on
   a separately-imported `db`, not on the fixture value (`test_qotm.py` etc.) — none
   of them call `.add()` directly on a fixture yielding `db`. I changed the fixture
   to `yield db.session` since it's the only way to satisfy the verbatim test
   bodies, and it required no change to the assertions/values the task actually
   cares about.

2. **Test pollution.** The brief's shown test code doesn't delete the practice rows
   it creates, even though the surrounding prose in the same document explicitly
   says to ("clean up rows you create instead" of `drop_all`/`create_all`). Running
   the tests as originally written left two orphan rows in the real local dev
   `practices` table (ids 4555, 4556 — deleted manually after discovery). I added
   `db_session.delete(practice)` + `commit()` at the end of each test to prevent
   this on every future run.

3. **Downstream test breakage.** `tests/practices/test_practice_migration_release.py`
   hardcodes the current migration head as `EVENTS_REVISION` and asserts
   `scripts/release.sh` lands there. Adding a migration on top of the previous head
   necessarily breaks this pin; updated it to the new head. This is expected,
   recurring upkeep for this test file whenever a new migration is appended — not
   specific to this task's design.

No other regressions found across the full non-wix_scrape suite.
